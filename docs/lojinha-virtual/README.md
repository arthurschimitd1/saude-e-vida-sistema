# Lojinha virtual

## Objetivo

A lojinha é uma vitrine comercial controlada pela empresa. Ela usa os produtos do estoque como origem, mas possui configuração própria para decidir o que será publicado.

## Regra de publicação

Um produto só aparece para o cliente quando:

1. foi adicionado à configuração da lojinha;
2. possui uma categoria criada para a loja;
3. está marcado como **Na loja**;
4. possui estoque disponível.

Remover o produto de uma seção como Destaques, Promoções ou Mais vendidos não remove o produto da loja. Essas seções são vitrines opcionais; o produto continua em **Todos**.

## Configuração do produto

Na configuração da lojinha é possível editar:

- nome exibido para o cliente, sem alterar o nome original do estoque;
- foto;
- categoria própria da loja;
- preço atual e preço anterior;
- descrição comercial;
- venda por unidade ou a granel;
- ordem e seções da vitrine;
- status de publicação.

O ID, código, estoque e vínculo do produto permanecem os mesmos.

## Produtos a granel

Produtos a granel usam o preço por quilograma. No produto, o cliente pode informar:

- o peso desejado para descobrir o valor;
- ou o valor desejado para descobrir quantos gramas serão comprados.

O estoque é baixado em quilogramas quando o pedido é confirmado.

## Checkout e pedidos

O checkout suporta login do cliente, cupom, Pix, cartão, retirada e entrega. A entrega é liberada para Campina Grande e Esperança/PB; para outras localidades, fica disponível somente a retirada na loja.

Pedidos aguardando pagamento não entram como compra concluída. A confirmação do pagamento atualiza o pedido e a gestão da lojinha.

## Pontos e cupons

Cada R$ 25 acumulados em compras gera 3 pontos. Compras vinculadas ao mesmo cliente são somadas, inclusive em dias diferentes. O saldo pode ser trocado por prêmios configurados no programa.

Cupons resgatados ficam vinculados ao cliente, têm validade definida e perdem a validade após o primeiro uso, tanto no site quanto no caixa.
