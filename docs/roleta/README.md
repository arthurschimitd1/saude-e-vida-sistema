# Roleta e programa de pontos

## Roleta promocional

A página pública coleta os dados do participante em etapas adequadas para tablet e registra nome, data de nascimento, telefone, e-mail e endereço. Depois do cadastro, o participante gira a roleta.

O giro:

- dura aproximadamente 4 segundos;
- usa as chances configuradas para os prêmios ativos;
- mostra a animação até o resultado final;
- gera um código individual para o participante;
- envia o prêmio e o código por e-mail quando o serviço de e-mail está configurado.

## Configuração de prêmios

Os prêmios são administrados em **Lojinha > Roleta e pontos**. Podem ser configurados:

- nome e descrição;
- custo em pontos;
- chance no giro;
- estoque opcional;
- desconto percentual;
- desconto fixo;
- produto grátis na compra.

No prêmio de produto grátis, não é necessário escolher um produto específico. O cliente deve ter pelo menos dois itens no carrinho. Uma unidade é concedida sem custo; se os produtos forem diferentes, o item de menor valor é o benefício. Também é possível vincular o prêmio a um produto específico.

## Cadastro do participante

Os dados da roleta chegam imediatamente à gestão. A equipe pode escolher cadastrar ou não o participante como cliente do sistema. O código do prêmio fica associado ao participante e ao cliente quando o cadastro é aprovado.

## Programa de pontos

O cliente recebe 3 pontos a cada R$ 25 acumulados em compras. O cálculo considera vendas do caixa vinculadas ao cliente e pedidos online confirmados. Valores de compras diferentes são acumulados até completar o bloco de R$ 25.

Os pontos podem ser trocados na área **Troque seus pontos**. Cada resgate cria um cupom exclusivo, com validade e limite de uso. O mesmo cupom não pode ser usado novamente depois de consumido no caixa ou na loja virtual.

## E-mail

O envio depende de um provedor configurado no backend. Sem a chave do provedor, o sistema mantém o prêmio e o código registrados, mas sinaliza que o envio de e-mail está pendente.
