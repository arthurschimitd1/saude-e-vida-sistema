# Saúde e Vida ERP

Primeira versão independente de um ERP para loja de produtos naturais.

## Como abrir

Inicie o servidor local (o arquivo direto `file://` mostra apenas a apresentação e não ativa as operações):

```bash
node server.js
```

Depois acesse `http://127.0.0.1:4173`.

## Acesso de demonstração

- E-mail: `admin@saudeevida.com`
- Senha: `saudevida123`

Os dados desta versão ficam em `data/saude-e-vida.json`, dentro deste projeto. Nenhum arquivo, banco ou configuração do LucroMais é usado pelo projeto.
